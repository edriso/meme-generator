# Meme Generator

A fun meme generator app built with React. Add custom text to random meme images!

## Features

- Fetches meme templates from the Imgflip API
- Add custom top and bottom text
- Generate random meme images

## Built With

- React
- Vite

## Getting Started

```bash
npm install
npm run dev
```
